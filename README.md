# EduSphere Learning Platform

Welcome to the EduSphere Learning Platform! This project is an interactive, modern web application designed to showcase the courses, events, and features of our educational institute. 

## Features
- **Responsive Design**: Looks great on both desktop and mobile devices.
- **Dynamic Content**: Explore various courses, campuses, and facilities.
- **Modern UI**: Clean and intuitive interface for an optimal user experience.
