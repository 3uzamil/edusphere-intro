EduSphere

A Complete Institute Management System

EduSphere is a comprehensive platform designed to streamline institute operations, providing dedicated portals for administration, teachers, students, and public website.

Developed by Syed Zain Raza Zaidi & Muzamil Hussain

Project Structure

Public Website

Built with HTML, CSS, JavaScript, React, and Tailwind CSS. The main responsive landing page for the institute, showcasing features, announcements, and general information to the public.

Admin Portal

Built with React and Vite. A centralized control panel for administrators to manage users, classes, subjects, assessments, and overall system settings.

Teacher Portal

Built with React and Vite. A dedicated workspace for teachers to manage classes, attendance, assignments, and grades efficiently.

Student Portal

Built with React and Vite. A personalized dashboard for students to view class content, submit assignments, track attendance, and view their profile.

Backend Server

A robust Node.js and Express backend connected to a MongoDB database. Provides secure RESTful APIs with JWT authentication and handles routing for classes, users, submissions, and grades.
